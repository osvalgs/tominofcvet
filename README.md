# Tomiño F.C. Veteranos

- index.html: página de los jugadores (próximo partido, cómo llegar, quién va, convocatoria publicada).
- entrenador.html: convocatoria con rotación, estadísticas por jugador y partidos.
- votacion.html: urna anónima en un solo móvil.
- hoja_google_script.gs: código de la hoja de Google que guarda asistencia y convocatorias.
- datos/temporada.json: datos de las actas (ya incluidos en los HTML).
